# 📋 Warehouse System - Історія змін
## Дата: 05 жовтня 2026

---

## 🎯 ЗАГАЛЬНИЙ ОГЛЯД

Проект: **Warehouse Management System** - веб-система для управління складськими операціями з функціоналом сортування картонів, управління палетами та ICC кодами.

---

## ✅ ЩО БУЛО РЕАЛІЗОВАНО

### 1. 📦 СИСТЕМА КОНТЕЙНЕРІВ (Priority 1.2)

**Дата реалізації:** 05.10.2026

**Що додано:**
- Таблиця `containers` в базі даних для зберігання контейнерів
- Таблиця `user_container_sessions` для відслідковування активних сесій
- API endpoints для роботи з контейнерами:
  - `GET /api/containers` - отримати активні контейнери
  - `POST /api/containers` - створити контейнер (admin)
  - `GET /api/containers/all` - всі контейнери з інфо про працівників
  - `PUT /api/containers/<id>/status` - змінити статус
  - `POST /api/container/select` - вибрати контейнер
  - `POST /api/container/end` - завершити роботу
  - `GET /api/container/current` - поточний контейнер
  - `GET /api/containers/sessions` - всі активні сесії

**Функціонал для Admin (Lider панель):**
- Таб "📦 Контейнери" для управління
- Створення нових контейнерів
- Перегляд хто працює з яким контейнером в реальному часі
- Управління статусом (активний/призупинений/завершений)

**Файли змінені:**
- `database.py` - додано методи для роботи з контейнерами
- `app.py` - додано API endpoints
- `templates/lider.html` - додано інтерфейс управління
- `static/lider.js` - додано JavaScript функції
- `migrate_add_containers.py` - міграція БД

**Результат:** Admin може створювати контейнери та бачити хто з ними працює

### 2. 🏭 СИСТЕМА СОРТІВ ЗОН/РАМП (Основний функціонал)

**Дата реалізації:** 05.10.2026

**Що додано:**
- Таблиця `sorts` для зберігання сортів (зон/рамп)
- Предвизначені зони:
  - **Zona Single A, B, C**
  - **Zona Mix A, B, C**
  - **Rampa 1, 2, 3, 4, 5, 6, 7, 8, 9**
- Можливість комбінувати типи картонів (Single + Mix + Vevor)
- Опціональна дата розвантаження
- Поле для приміток

**API endpoints:**
- `GET /api/sorts` - активні сорти для користувачів
- `GET /api/sorts/all` - всі сорти (admin)
- `POST /api/sorts` - створити сорт (admin)
- `GET /api/sorts/<id>` - інформація про сорт
- `PUT /api/sorts/<id>` - оновити сорт
- `PUT /api/sorts/<id>/status` - змінити статус
- `DELETE /api/sorts/<id>` - видалити сорт

**Інтерфейс в Admin панелі:**
- Новий таб "Сортування" → підвкладка "Створити сорт"
- Вибір типу локації (Zona Single, Zona Mix, Rampa)
- Вибір конкретної локації з випадаючого списку
- Чекбокси для вибору типів картонів (можна кілька)
- Опціональна дата розвантаження
- Поле для приміток
- Попередній перегляд сорту
- Список активних сортів з можливістю закриття/видалення

**Інтерфейс для користувачів:**
- Вибір активного сорту після натискання кнопки SORT
- Відображення інформації про сорт (назва, тип, дата)
- Можливість змінити сорт

**Файли змінені:**
- `database.py` - методи для роботи з сортами
- `app.py` - API endpoints для сортів
- `templates/admin.html` - інтерфейс створення сортів
- `static/admin.js` - JavaScript функції
- `templates/dashboard.html` - вибір сорту для користувачів
- `static/dashboard.js` - логіка роботи з сортами
- `migrate_add_sorts.py` - міграція БД

**Результат:** 
- Admin може створювати сорти для різних зон та рамп
- Користувачі вибирають сорт перед початком роботи
- Система відслідковує хто з яким сортом працює

## 📁 СТРУКТУРА БАЗи ДАНИХ

### Нові таблиці:

**containers:**
- `id` - PRIMARY KEY
- `container_number` - TEXT UNIQUE
- `status` - TEXT (active/paused/completed)
- `created_at` - TIMESTAMP
- `completed_at` - TIMESTAMP

**sorts:**
- `id` - PRIMARY KEY
- `name` - TEXT (назва зони/рампи)
- `type` - TEXT (типи картонів через кому)
- `unload_date` - DATE
- `description` - TEXT
- `status` - TEXT (active/paused/closed)
- `created_at` - TIMESTAMP
- `created_by` - INTEGER (FK users)
- `closed_at` - TIMESTAMP

**user_container_sessions:**
- `id` - PRIMARY KEY
- `user_id` - INTEGER (FK users)
- `container_id` - INTEGER (FK containers)
- `sort_id` - INTEGER (FK sorts)
- `started_at` - TIMESTAMP
- `ended_at` - TIMESTAMP
- `is_active` - INTEGER (0/1)

### Змінені таблиці:

**icc_codes:**
- Додано поле `sort_id` - INTEGER (FK sorts)
- Додано поле `container_id` - INTEGER (FK containers)

## 🎮 ІНСТРУКЦІЯ ДЛЯ ADMIN

### Як створити сорт:

1. Увійти як admin (`admin` / `admin1324`)
2. Перейти в **Admin панель** → **Сортування** → **Створити сорт**
3. Обрати **Тип локації**:
   - Zona Single (A, B, C)
   - Zona Mix (A, B, C)
   - Rampa (1-9)
4. Обрати **конкретну локацію** з випадаючого списку
5. Вибрати **типи картонів** (можна кілька):
   - ☐ Single
   - ☐ Mix
   - ☐ Vevor
6. *Опціонально:* вказати дату розвантаження
7. *Опціонально:* додати примітки
8. Натиснути **"✓ Створити сорт"**

### Приклади сортів:

**Приклад 1:** Single в Зоні А
- Тип: Zona Single → A
- Типи: ☑ Single
- Результат: `Zona Single A — Single`

**Приклад 2:** Mix + Single на Рампі 5
- Тип: Rampa → 5
- Типи: ☑ Single ☑ Mix
- Результат: `Rampa 5 — Single + Mix`

**Приклад 3:** Всі типи в Зоні Mix B
- Тип: Zona Mix → B
- Типи: ☑ Single ☑ Mix ☑ Vevor
- Результат: `Zona Mix B — Single + Mix + Vevor`

### Управління активними сортами:

- **Закрити сорт** - сорт більше не доступний для користувачів
- **Видалити сорт** - повністю видаляє сорт та всі пов'язані дані
