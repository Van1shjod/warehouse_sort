# Warehouse System

Вебзастосунок для розвантаження та сортування картонів на складі.

## Можливості

- **Pre-sort:** адміністратор створює завдання; працівники сканують картони
  на пронумеровані палети та закривають їх після заповнення.
- **Sort:** Single і Mix, режими «Один товар» та «Різні товари».
  Vevor поки показує повідомлення «У розробці».
- **Один товар:** система проводить по палетах-джерелах, підтверджує кожен
  картон і веде облік зібраного за працівником. Порядок обходу можна змінити.
- **OCR:** розпізнавання наклейки після фото, автоматичне продовження при повних
  даних; неповний або неправильний скан не додає картон.
- **ID Pack:** апаратний сканер Single/Mix, групування зі збереженням початкових
  нулів, лічильник, ручна кількість і повні ID у групах адмінпанелі.
- **Адмінпанель:** завдання, користувачі, архів Pre-sort, залишки, журнал рухів,
  коригування, закриття та видалення завдань із підтвердженням.
- Світла й темна теми; українська, англійська, польська та російська мови.
  Вибір мови доступний на сторінці входу/реєстрації.

## Запуск

У папці проєкту:

```powershell
python -m pip install -r requirements.txt
python app.py
```

Локальна адреса: http://localhost:5000.
Для запуску з Cloudflare є `start_server.bat` та `cloudflared.exe`.
Адресу тунелю потрібно брати з поточного запуску.

### Termux на Android

Помістіть повну актуальну папку проєкту в домашню папку 64-бітного Termux,
наприклад `~/warehouse-system`, та виконайте

```bash
cd ~/warehouse-system
bash start_termux.sh
```

Перший запуск встановлює Ubuntu 24.04 через PRoot-Distro, Python, залежності OCR,
Waitress і Cloudflare. Середовище зберігається для наступних запусків. Для OCR
обрано Linux-середовище Ubuntu з Python 3.12 та окремими сумісними діапазонами
пакетів у скрипті. Опис встановлення контейнера є в [документації PRoot-Distro](https://github.com/termux/proot-distro).

Скрипт запускає сервер, показує публічну адресу й відкриває її у браузері.
Cloudflare видає тимчасове посилання `trycloudflare.com` за схемою
[Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).
Зупинка сервера й тунелю виконується через **Ctrl+C** у Termux.
Для іншого порту можна виконати `PORT=5050 bash start_termux.sh`.

Резервні копії SQLite перед запуском, журнали та остання адреса зберігаються в
`.termux/`. Скрипт утримує wake lock під час роботи. Android має дозволяти
Termux працювати у фоні. Папку зі спільного сховища `/sdcard` слід спочатку
скопіювати до домашньої папки Termux.

Перевірено Bash-синтаксис, довідку та ізольовані сценарії запуску із заміненими
командами Termux/Cloudflare, включно з резервною копією, зайнятим портом,
помилкою сервера та зупинкою дочірніх процесів. На фізичному Android-пристрої
встановлення Ubuntu й OCR ще потребує перевірки.

Робоча `warehouse.db` вже підготовлена: порожні завдання й облік, збережений
акаунт адміністратора з поточним паролем. Нових працівників можна реєструвати
через сайт або створювати в адмінпанелі.

## Файли

- `app.py`, `database.py` — сервер та SQLite.
- `presort.py`, `sorting.py` — завдання й робочі операції.
- `inventory.py`, `inventory_migration.py` — журнал рухів і поточні залишки.
- `ocr_labels.py` — актуальне розпізнавання наклейок.
- `presentation/` — презентації українською, англійською, польською та російською.
- `templates/`, `static/` — інтерфейс, локалізація, теми та сканер.
- `migrate_*.py` — обслуговування старих схем бази; не запускати без потреби.
- `test_*.py`, `test_*.cjs` — актуальні автоматичні перевірки.
- `AGENTS.md`, `PROJECT_CONTEXT.md`, `PRE_SORT.md` — інструкції та контекст.
- `archive/cleanup-2026-11-02/` — відкладені старі матеріали, не використовуються
  сайтом; список у `CLEANUP_REVIEW.md`.

Фотографії та результати нових OCR-сканувань зберігатимуться в
`ocr_training_data/`. Старі знімки й журнали очищено 02.11.2026.

## Перевірки

```powershell
python -m unittest test_sorting test_api_regressions test_presort test_ocr_labels test_collection test_ocr_corrections -v
node --test test_data_version.cjs test_i18n.cjs test_presort_camera.cjs test_sort_presort.cjs test_admin_presort.cjs test_back_navigation.cjs test_admin_navigation.cjs test_sort_workflow.cjs
```

Перевірки обліку використовують тимчасові бази. Клас перевірок за історичними
фото пропускається після погодженого видалення цих фото. Парсер і робочі
OCR-маршрути мають окремі тести.
