## 🔄 ЯК ВІДНОВИТИ З РЕЗЕРВНОЇ КОПІЇ

Якщо потрібно повернутись до початкового стану:

### Крок 1: Зупинити сервер
```bash
# Знайти процес
netstat -ano | grep :5000

# Зупинити (замінити PID на свій)
taskkill /PID <номер_процесу> /F
```

### Крок 2: Відновити файл
```bash
# Приклад відновлення database.py
cp backup_initial/database.py.backup database.py

# Або для всіх файлів:
cp backup_initial/*.backup .
# І прибрати розширення .backup
```

### Крок 3: Видалити нові міграції (якщо потрібно)
```bash
rm migrate_add_containers.py
rm migrate_add_sorts.py
```

### Крок 4: Відновити базу даних
```bash
# Видалити поточну БД
rm warehouse.db

# Запустити сервер (створить нову БД)
python app.py
```
