📱 Перевірка AutoID Q9 сумісності

Специфікації AutoID Q9 (SEUIC Q9):

  • Екран: 480 × 800 пікселів
  • Діагональ: 4 дюйми
  • DPI: ~233 точок на дюйм
  • Орієнтація: Портретна (вертикальна)

Метод 1: Через Chrome/Edge DevTools (Рекомендовано)

📐 Крок за кроком:

  1. Відкрийте сайт у Chrome або Edge: http://127.0.0.1:5000
  2. Натисніть F12 (відкриється панель розробника)
  3. Натисніть Ctrl+Shift+M або клацніть на іконку 📱 (Toggle device toolbar)
  4. Вгорі у списку пристроїв виберіть "Responsive"
  5. Встановіть розміри:
    • Ширина: 480
    • Висота: 800
  6. Перевірте всі сторінки: Dashboard, Sort, Pre-sort, Admin

➕ Додати власний пристрій "AutoID Q9":

  1. У режимі емуляції пристрою клацніть на список пристроїв
  2. Виберіть "Edit..."
  3. Натисніть "Add custom device"
  4. Заповніть:
    • Device name: AutoID Q9
    • Width: 480
    • Height: 800
    • Device pixel ratio: 1
    • User agent: (залишити за замовчуванням)
    • Device type: Mobile
  5. Натисніть "Add"

Метод 2: Зміна розміру вікна браузера

🪟 Простий спосіб:

  1. Відкрийте сайт у новому вікні браузера
  2. Зменшіть ширину вікна до ~480px (наскільки можливо)
  3. Встановіть масштаб 100% (Ctrl+0)
  4. Перевірте, чи все видно без горизонтальної прокрутки

Метод 3: Демо-перегляд нижче

AutoID Q9 (480×800px)

✅ Що перевіряти:

  • ✓ Немає горизонтальної прокрутки
  • ✓ Всі кнопки доступні і не обрізані
  • ✓ Текст читабельний (не надто дрібний)
  • ✓ Форми вміщуються на екрані
  • ✓ Навігаційна панель компактна (48px)
  • ✓ Камера займає ~34% висоти екрана
  • ✓ Модальні вікна відкриваються зверху
  • ✓ Toast-повідомлення видно
  • ✓ ID Pack форми працюють коректно
⚠️ Важливо:
  • Handheld CSS активується автоматично при viewport ≤480×850px
  • Для реального Q9 можлива додаткова адаптація через Android WebView
  • Перевірте всі 4 мови (UK/EN/PL/RU)
  • Протестуйте світлу та темну теми

Швидка перевірка критичних сценаріїв:

  1. Вхід: Форма входу видно повністю
  2. Dashboard: Кнопки SORT/PRE-SORT не перекриваються
  3. Sort Single: Камера + форма вміщуються
  4. Sort Mix: Все поле введення коду видно
  5. ID Pack: Поле коду + лічильник в один ряд
  6. Pre-sort: Камера залишається відкритою після додавання
  7. Admin: Таблиці з горизонтальною прокруткою працюють
